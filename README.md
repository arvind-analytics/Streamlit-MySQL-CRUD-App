# Streamlit MySQL CRUD Application

This is a dynamic and interactive Python web application built using *Streamlit* that performs full *CRUD (Create, Read, Update, Delete)* operations on a *MySQL* database.

## 🚀 Features
- *Create*: Add new user records (Name & Email) directly into the database.
- *Read*: Fetch and display all stored records in real-time.
- *Update*: Modify existing user details seamlessly via the web UI.
- *Delete*: Remove user records from the database safely.

## 🛠️ Technologies Used
- *Frontend:* Streamlit (Python Framework)
- *Backend:* Python
- *Database:* MySQL
- *Driver:* mysql-connector-python
